## Key Types & Interfaces

### InMemoryTxPool (crates/app/src/tx_source.rs)
- Inner: `Mutex<Vec<Vec<u8>>>` (raw EIP-2718 encoded tx bytes)
- `push(&self, tx: Vec<u8>)` — add tx
- `pending(&self) -> Vec<Vec<u8>>` — drain all (FIFO)
- Implements `TxSource` trait
- Already `Arc<InMemoryTxPool>` in main.rs

### TxSource trait (crates/app/src/traits.rs)
- `fn pending(&self) -> Vec<Vec<u8>>`

### Application trait (crates/app/src/traits.rs)
- `propose(txs) -> Block`
- `verify(block) -> Result`
- `genesis() -> Result`
- Associated types: Block, Result, Error

### EvmApplication (crates/app-evm/)
- Constructed with: `WhirlpoolEvmConfig`, `StateDb impl`, `Arc<InMemoryTxPool>`
- Executes EVM transactions, produces blocks

### StateDb trait (crates/state/src/traits.rs)
- `get_account(address: Address) -> Option<AccountInfo>`
- AccountInfo: `balance: U256`, `nonce: u64`, `code_hash: B256`
- Also: `get_storage`, `get_code_by_hash`, `get_block_hash`, `state_root`, `commit`
- InMemoryStateDb stores: `DbAccount { info: AccountInfo, storage: HashMap<U256, U256> }`
- State DB in main.rs: `Arc<RwLock<TestStateDb>>` — clonable for sharing with RPC

### StateProvider trait (crates/app-evm/src/traits.rs)
- Blanket impl delegating to state::traits::StateDb
- Provides account state reads (balance, nonce, code, storage)

### EvmBlock (crates/app-evm/ or app/)
- Fields: height, parent_id, state_root, transactions_root, receipts_root, gas_used, timestamp, transactions (raw bytes)

### ExecutionResult (crates/app-evm/)
- Fields: state_root, receipts_root, gas_used, receipt_count
- **CRITICAL**: Receipts generated by BlockExecutor::finish() but DROPPED after computing receipts_root — NOT stored

### Finalization flow
- FinalizationSink → AtomicU64 height tracker
- ConsensusApp → CommonwareEngine → MailboxActor → AppAdapter → FinalizationSink::handle

### whirlpool-node main.rs wiring
- `tx_pool = Arc::new(InMemoryTxPool::new())`
- `state_db = Arc::new(RwLock::new(TestStateDb::new(...)))`
- `evm_app = EvmApplication::new(evm_config, state_db.clone(), tx_pool.clone())`
- `app = Arc::new(ApplicationAdapter::new(evm_app))`
- Engine started, then `pending::<()>().await` (no RPC server)
- **state_db can be cloned before passing to EvmApplication for RPC access**

## Gaps (design must address)
1. **Receipt storage**: Receipts dropped after hash — need in-memory receipt store indexed by tx hash
2. **Gas estimation**: Need EVM dry-run — clone state, build EVM env, binary-search gas with transact() without committing
3. **Block number**: Need to expose current block height to RPC (finalization height tracker is AtomicU64)
4. **RPC port config**: Need configurable bind address for JSON-RPC server
