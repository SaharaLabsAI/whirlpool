## Blockers
- BLOCKER (INV-01, INV-06): Proposal wiring is functionally empty for tx execution (`transactions: vec![]`, empty roots, `gas_used: 0`), so execution artifacts for non-empty inputs are not produced.
- BLOCKER (INV-02): Verification wiring checks only `state_root`; missing replay/recompute checks for transactions root, receipts root, and gas usage.
- BLOCKER (INV-01): Runtime default tx provider is `NoopTxSource`, so non-empty transaction ingestion is absent in grounded wiring.
- UNKNOWN/BLOCKER (INV-04): Snapshot/rollback mechanism for failed propose/verify is not evidenced in EVM execution wiring.
- BLOCKER (INV-05): Finalize-to-commit linkage for canonical state application is not evidenced at the EVM execution boundary; state commit exists but integration seam is missing from in-scope consensus app callbacks.
