## Blockers
- BLOCKER (INV-01, INV-06): Runtime wiring uses `NoopTxSource` (`crates/whirlpool-node/src/main.rs::main`), so block proposal input is empty by default; non-empty execution visibility/root consistency are blocked.
- BLOCKER/PARTIAL (INV-02): Verification integrity is only partially represented in current app path (shared context evidence: verify is state-root check oriented), so artifact-level mismatch detection remains incomplete.
- BLOCKER (INV-05): No visible finalize-to-commit wiring in in-scope node + consumed consensus app contract (`ConsensusApp` has no finalize callback), preventing grounded ownership of atomic canonical commit.
- UNKNOWN (INV-04): Snapshot/rollback wiring point for failed propose/verify is not explicit in provided node/consensus evidence.
- UNKNOWN (INV-07 for non-empty flows): Deterministic ordering/selection policy for non-empty tx proposals is not grounded by current `TxSource::pending()`-based wiring evidence.
