# 20 - Vendor agent-docs Workflow

Before reading source code in any vendor subproject, start from agent-docs when available.

## Entry points

- Commonware: `vendor/commonware/agent-docs/index.md`
- Reth: `vendor/reth/agent-docs/index.md`
- Alto: `vendor/alto/agent-docs/index.md`

## Progressive reading inside a vendor project

1. `agent-docs/index.md`
2. Relevant `agent-docs/overview/*`
3. Relevant `agent-docs/architecture/*`
4. Relevant `agent-docs/guides/*`
5. Relevant `agent-docs/reference/*`

This order is meant to build context progressively from broad to specific.
