## Context
`test_engine_can_be_constructed` fails with:
> "Cannot drop a runtime in a context where blocking is not allowed. This happens when a runtime is dropped from within an asynchronous context."

The `test_context()` helper in `engine.rs` creates a `commonware_tokio::Context` via `spawn_blocking` + `Runner::default().start()`. The resulting context holds a runtime that panics when dropped inside a `#[tokio::test]` async context.

This sub-task fixes the test infrastructure so the engine can be constructed in tests — prerequisite for all subsequent wiring work.

## What to do
1. **Diagnose** the exact `test_context()` implementation in `engine.rs` tests module (around line 180+).
2. **Fix** the context lifecycle so it doesn't panic on drop:
   - Option A: Move context creation outside the async runtime (use `std::thread::spawn` for context creation and keep it alive via an `Arc` or channel).
   - Option B: Use `commonware_runtime::deterministic::Context` for unit tests instead of `commonware_tokio::Context` (vendor tests use deterministic runtime).
   - Option C: Ensure the context's inner runtime is properly shut down before the tokio test runtime drops it.
3. **Verify** `test_engine_can_be_constructed` passes.
