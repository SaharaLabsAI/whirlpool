# Task 4: Close Mailbox/MailboxActor Gaps - Evidence

## Problem Statement
AppAdapter Reporter implementation used wrong Activity type: `Activity<Sig, <B as Committable>::Commitment>` instead of `Activity<Sig, Digest>` where `Digest = sha256::Digest`.

## Root Cause
Confusion between:
- **Marshaled layer**: `Update<B>` (application-level bridge in `Marshaled` wrapper)
- **Raw layer**: `Activity<Sig, Digest>` (protocol-level, used by raw `simplex::Engine`)

Our design uses raw `simplex::Engine`, so `Activity::Finalization.proposal.payload` is a `Digest` (sha256 hash), NOT a Block.

## Solution Implemented

### 1. Fixed AppAdapter Reporter Activity Type
**File**: `crates/consensus-simplex/src/adapter.rs`

**Changes**:
- Line 11: Added `use commonware_cryptography::sha256::Digest;`
- Line 154: Changed `type Activity = Activity<Sig, <B as Committable>::Commitment>` → `Activity<Sig, Digest>`
- Lines 160-180: Fixed match handlers to treat `proposal.payload` as Digest:
  ```rust
  Finalization(fin) => {
      let commitment = fin.proposal.payload;  // Already a Digest
      if let Some(block) = self.finalized_blocks.remove(&commitment) {
          let height = Heightable::height(&block).get();
          self.sink.handle(ConsensusEvent::Finalized { block, height, proof: vec![] }).await;
      } else {
          warn!(?commitment, "finalization received for unknown block");
      }
  }
  ```

### 2. Added Type Constraint Throughout
To ensure `<B as Committable>::Commitment` matches vendor's `Digest` type:

**AppAdapter struct** (line 36-43):
- Changed `where B: Committable` → `where B: Committable<Commitment = Digest>`
- Changed HashMap key from `<B as Committable>::Commitment` → `Digest`

**All impl blocks** (lines 48, 73, 147, 192):
- Added constraint: `B: Committable<Commitment = Digest>`
- Removed redundant: `<B as Committable>::Commitment: Eq + std::hash::Hash` (implied by Digest)

### 3. Engine Type Constraints
**File**: `crates/consensus-simplex/src/engine.rs`

- Line 11: Added `use commonware_cryptography::Committable;`
- Line 94: Added constraint `A::Block: Committable<Commitment = Digest>` to ensure block's commitment type matches vendor's digest type
