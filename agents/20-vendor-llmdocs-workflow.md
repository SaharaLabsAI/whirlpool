# 20 - Vendor llmdocs Workflow

Before reading source code in any vendor subproject, start from llmdocs when available.

## Entry points

- Commonware: `vendor/commonware/llmdocs/index.md`
- Reth: `vendor/reth/llmdocs/index.md`
- Alto: `vendor/alto/llmdocs/index.md`

## Progressive reading inside a vendor project

1. `llmdocs/index.md`
2. Relevant `llmdocs/overview/*`
3. Relevant `llmdocs/architecture/*`
4. Relevant `llmdocs/guides/*`
5. Relevant `llmdocs/reference/*`

This order is meant to build context progressively from broad to specific.
